# BoxShot 帮助

菜单栏常驻的轻量截图 / 标注 / OCR / 录屏工具，原生 macOS 应用（macOS 14 及以上）。

这份文档只讲**怎么用**。想知道某个功能为什么这么做、踩过什么坑，看仓库的 README。

> 这份文档随应用一起安装，在「设置 → 关于 → 帮助文档」里随时能打开，不需要联网。

---

## 一、三分钟上手

1. **截图**：点菜单栏的相机图标 → 「区域截图」（或按你自己设的热键）→ 拖一个框 → **松手就截好了**。
2. **标注**：截完会在原位弹出标注浮层，工具条就在选区旁边。画箭头、写字、打码、编号都在这儿。
3. **输出**：点「复制」进剪贴板 / 「保存」落盘 / 「贴图」钉在屏幕上 / 或直接按 ⏎ 走默认动作。

浮层里按 **Esc** 取消这一次截图，不会留下任何文件。

---

## 二、第一次使用要授权

- **屏幕录制**（必需）—— 第一次截图 / 录屏 / OCR 时要。没给的话截图打不开，或截出一张纯黑图。
- **辅助功能**（可选）—— 只在「智能元素截取」和窗口高亮时用。没给就退化成只高亮整窗，其余照常。
- **输入监控**（可选）—— 用全局热键时要。没给则热键不触发。

授权路径：**系统设置 → 隐私与安全性 → 屏幕录制** → 勾上 BoxShot → **把应用退出再打开**（改完不重启不生效）。

> 更新版本后如果功能突然不触发了，去上面的列表里把 BoxShot 那一项**删掉重勾**一次即可。原因是系统把授权记在签名指纹上，正常情况下我们已经让它在跨版本时保持稳定。

---

## 三、能截什么

菜单栏图标里一共有这几种入口：

- **区域截图** —— 拖框选一块，松手即截。拖的时候光标旁边有放大镜（显示坐标、区域尺寸和色值）。
- **窗口截图** —— 进模式后鼠标停在哪扇窗上就高亮哪扇，**轻点一下**即截；圆角窗口截出来是带圆角的干净图，不带桌面背景。
- **全屏截图** —— 截鼠标所在的那块屏。多显示器只做单屏，不做跨屏拼接。
- **智能元素截取** —— 主要给网页用。光标一动就高亮光标底下那个 UI 元素（按钮 / 链接 / 输入框 / 列表行），提示条会写「172 × 40 · 单击截取「链接：产品」」，单击即截。一次没框准、框成了整页区块，就把鼠标再往元素中心挪一点。
- **滚动截图** —— 截长网页 / 长聊天记录。选好区域后按提示滚动，工具会自动抓帧拼接，旁边有个缩略图窗口实时跟着变长。开始滚之前还能拖手柄改选区大小，**一滚就锁定**。
- **重复上次区域** —— 上次的框还记得，直接再来一张。

## 四、标注

打开标注界面时**默认就是箭头**（截十次有九次是拿箭头指一下）。

工具条从左到右大致是：选择 / 箭头 / 画笔 / 矩形 / 椭圆 / 直线 / 步骤标注 / 文字 / 马克笔 / 马赛克 / 模糊 / 测距 / 取色 / 高亮，然后是颜色、粗细、字号，最后是撤销、重做和输出。

几个容易忽略的点：

- **粗细**（`px` 下拉，5 档）和**字号**（`pt` 下拉，6 档）**选过就记住**，下一张截图还是它。
- **步骤标注**：点一下画布放一个圆底编号，序号自动递增；**删掉中间一步，后面的自动补号**（不用手动改）。
- **文字**：点画布直接打字，**回车确认，Esc 取消**；正在输入时也能改字号和颜色，所见即所得。
- **马赛克 / 模糊**：拖出一个区域，整块生效，底图不会被破坏，随时能撤销。
- **高亮**：拖一个矩形，块内保留原样、块外压暗。
- **裁剪**：拖出要保留的范围，按 ⏎ 应用。
- **选中已有标注**：切到「选择」工具点一下，可以拖动、改颜色 / 粗细 / 字号、按 ⌫ 删除。
- **美化**：给截图套一层背景 + 圆角 + 阴影（参数随时可改，不烧进底图）。
- 撤销 ⌘Z、重做 ⇧⌘Z，**最多 50 步**。

## 五、OCR 识别与翻译

对一张图按 OCR，结果会弹在独立窗口里，同时（默认）已经把文字复制到剪贴板。

- **中英混排**识别没问题；没有汉字的图（纯英文界面、代码、公式）会自动关掉中文语言纠正再识别一遍，准确率更高。
- **表格图**会顺带重排成 Markdown，结果窗里多一个「复制为 Markdown」按钮，粘到备忘录 / Typora 直接成表。
- **翻译**用系统自带的离线翻译（macOS 15 及以上，不联网、不要密钥），目标语言可选中文 / 英文，默认按文字本身猜方向。

### 「保留原文」勾选框

在结果窗左下角、语言下拉右边：

- **勾上** → 变成**逐句对照**：原文在上（浅色）、译文在下（深色）。
- **不勾** → 整段替换成译文（默认）。
- 勾选状态会被记住，下次打开还是它。
- 切换勾选会**当场重新翻译一遍**（对照要"一行对一行"的数据，整段译文里没有这个结构）。

### 复制

结果窗的「复制」按当前看到的形态走：

- **逐句对照**时 —— 复制**原文 + 译文**，逐句交替（和屏幕上看到的一致）
- **整段译文**时 —— 只复制译文
- **还没翻译**时 —— 复制原文

## 六、二维码 / 条形码

对图里的码走「解码」，支持 11 种常见码制（QR、Data Matrix、Code 39/93/128、EAN、PDF417 等）。解不出来时会自动用「放大 / 拉对比 / 膨胀」再试一轮，圆点风格的分享码也能认。结果窗里是网址的会直接给一个「打开」按钮。

---

## 七、测距与取色

- **测距**：全屏遮罩上拉一条线，按**物理像素**报数（不是屏幕点），提示条里会写清楚。
- **取色**：标注工具条里的吸管，点一下取色并把色值（HEX）复制到剪贴板。

---

## 八、贴图

把截图或剪贴板里的图“钉”在屏幕上：

- 从截图浮层点「贴图」，或菜单「从剪贴板贴图」，或把图片文件拖到菜单栏图标上。
- 滚轮缩放、双向翻转、双击动作可选、历史可恢复。
- **文本贴图里的文字可以直接选中复制**。
- 每张贴图右上角有**置顶按钮**（鼠标悬停才出现）。
- 右键「编辑贴图」能再进编辑器加标注。

---

## 九、录屏

- **区域 / 全屏 / 窗口录制**三种。窗口录制是点一下目标窗口、自动填好框，后面和区域录制完全一样。
- **声音**：系统声音和麦克风二选一（互斥）。系统声音需要在系统里额外授权一次。
- **摄像头画中画**：菜单「摄像头录制」，先摆一个固定录制框（可用区 75%，16:9），框里录屏、大摄像头画面居中。
- 录制中工具条带计时，**可以暂停 / 恢复**，工具条也能拖着挪走（它会尽量不出现在成片里）。
- 格式 MOV / MP4，可选帧率和画质。

---

## 十、截图历史

- 每张截下来的图都留一份在本地，**默认保留最近 20 张**（设置里能改，设成 0 就是不记录）。
- 菜单「截图历史…」打开网格视图：双击进编辑器，右键可以复制 / 贴图 / 在 Finder 中显示 / 删除。
- 选中一张按**空格**可以 QuickLook 预览。
- 底部会显示全部图片的磁盘占用，攒多了可以一键「清空全部」。
- 存储位置：`~/Library/Application Support/BoxShot/History/`

## 十一、快捷键

**出厂不带任何全局热键**（避免和系统或别的应用撞车）。要热键的话：**设置 → 快捷键**，自己录一个。

建议：

- 区域截图：`F7` 或 `⌥A` 这类不常用的组合
- 全屏截图、贴图、OCR 可以各给一个

录完立刻生效，不用重启。

---

## 十二、设置里有什么

顶部分七组：**通用 / 截图 / 贴图 / OCR / 录制 / 快捷键 / 关于**。

- **通用**：开机启动、隐藏 Dock 图标、内存回收（占用到 300MB 且空闲 60 秒时自动重开一次自己，把界面内存还给系统；30 分钟内最多一次，可以关掉）。
- **截图**：截图后是否直接弹标注浮层、是否复制到剪贴板、保存目录、保存格式、图片质量、Retina 降采样、光标处的放大镜、窗口高亮、提示音。
- **贴图**：贴图透明度、阴影、双击动作。
- **OCR**：是否保留换行、是否追加到剪贴板、是否自动打开识别到的链接、结果是否保持上次位置。
- **录制**：帧率、画质、格式、声音来源、摄像头取景框大小、录制结束是否在 Finder 里显示。
- **关于**：版本、作者、**帮助文档**入口。

## 十三、常见问题

**截出来是黑的 / 一点反应都没有**
屏幕录制授权没给或给了没重启应用。去「系统设置 → 隐私与安全性 → 屏幕录制」检查，改完退出应用再打开。

**更新版本之后功能失灵了**
同上，把列表里 BoxShot 那一项删掉重新勾选一次。

**翻译点了没反应 / 提示「这段文字已经是英文了」**
目标语言和文字本身是同一种语言，系统框架会直接拒绝。换个方向即可。另外翻译需要 macOS 15 及以上并装好对应语言包（第一次用会弹系统下载框）。

**OCR 结果窗里看不到内容**
先看顶部是不是「对照」模式 —— 逐句对照会把每句话拆成两行，长文要往下滚。想看点紧凑的就把「保留原文」勾掉。

**截图历史是空的**
检查设置 → 截图里的历史张数是不是 0；确认应用对 `~/Library/Application Support/BoxShot/` 有写权限。

**菜单、弹出面板这类浮窗截不到**
菜单（点开的菜单列表）没法截：它开着时任何操作都会先把它关掉，系统自带截图也一样。弹出面板（菜单栏图标点开的那个卡片）可以截 —— 截图时画面会**冻结**，你看到的就是最后拿到的那一帧，所以浮窗不会在你框的时候突然消失。

**框选的时候画面不动了**
这是有意的：截图一触发就先拍下一帧静止画面，你在它上面框。好处是所见即所得，浮窗、弹窗、动画都不会"框的时候有、出图的时候没"。

**内存占用看起来偏高**
截图后剩余的那部分主要是系统（Core Animation）还没回收的图层缓存，跟应用里是否泄漏无关。开着「内存回收」的话，占用到 300MB 且空闲 60 秒会自动重开一次。
